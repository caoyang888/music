## 版本怎么记

`故事名/编号-本版改进方向/`。第 01 版用初稿的写作切口命名。每个故事独立从 01 编号；后续用 02、03……另开目录，编号不因歌名改变而重排，不覆盖旧版本。

每版至少有 `歌词.md` 和 `制作记录.md`。从第 02 版起，制作记录注明基于哪一版、为什么改、改了什么、试唱或试听结果。做编曲试验时，另外记录所用歌词版本，以及有实际记录的速度、调性、配器、生成条件和试听结论，避免只凭文件名回忆。

推进顺序：先把歌词写出来，再讨论音乐方向；MV 等音乐做好再开始。
